## Endpoints

| Método | Caminho | Descrição |
|--------|---------|-----------|
| `POST` | `/projects` | [Criar um projeto](/api-reference/projects/create-project) |
| `POST` | `/tasks` | [Criar uma tarefa](/api-reference/tasks/create-task) |
| `GET` | `/projects/{project_id}/tasks` | [Listar tarefas de um projeto](/api-reference/tasks/list-tasks) |

| `DELETE` | `/tasks/{task_id}` | [Deletar uma tarefa](/api-reference/tasks/delete-task) |

## Modelos de dados

### Project

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `project_id` | string (UUID) | Identificador único. Gerado automaticamente. |
| `name` | string | Nome do projeto. |
| `description` | string ou null | Descrição opcional. |
| `created_at` | string (ISO 8601) | Timestamp de criação. |

### Task

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `task_id` | string (UUID) | Identificador único. Gerado automaticamente. |
| `project_id` | string (UUID) | O projeto ao qual esta tarefa pertence. |
| `title` | string | Título da tarefa. |
| `description` | string ou null | Descrição opcional. |
| `status` | `pending`, `in_progress` ou `done` | Status atual da tarefa. |
| `created_at` | string (ISO 8601) | Timestamp de criação. |
| `updated_at` | string (ISO 8601) | Timestamp da última atualização. |

### Error

| Campo | Tipo | Descrição |
|-------|------|-----------|
| `error` | string | Tipo curto do erro (ex: `"Not Found"`). |
| `message` | string | Explicação legível por humanos. |

## Observações

<Note>
  A API pode levar até 60 segundos para responder na primeira requisição após inatividade. Isso é esperado, então aguarde alguns segundos e tente novamente.
</Note>

- Todos os bodies de requisição devem usar `Content-Type: application/json`
- Todos os timestamps são UTC no formato ISO 8601
- Todos os IDs são UUIDs (versão 4)
- Campos desconhecidos enviados no body são silenciosamente ignorados
- A exclusão é permanente e não pode ser desfeita
