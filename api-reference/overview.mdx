|--------|------|-------------|
| `POST` | `/projects` | [Create a project](/api-reference/projects/create-project) |

## Data models

### Project

| Field | Type | Description |
|-------|------|-------------|
| `project_id` | string (UUID) | Unique identifier, auto-generated |
| `name` | string | The project name |
| `description` | string or null | Optional description |
| `created_at` | string (ISO 8601) | Creation timestamp |

### Task

| Field | Type | Description |
|-------|------|-------------|
| `task_id` | string (UUID) | Unique identifier, auto-generated |
| `project_id` | string (UUID) | The project this task belongs to |
| `title` | string | The task title |
| `description` | string or null | Optional description |
| `status` | `pending`, `in_progress`, or `done` | Current task status |
| `created_at` | string (ISO 8601) | Creation timestamp |
| `updated_at` | string (ISO 8601) | Last update timestamp |

### Error

| Field | Type | Description |
|-------|------|-------------|
| `error` | string | Short error type such as `"Not Found"` |
| `message` | string | Human-readable explanation |

## Notes

<Note>
  The API may take up to 60 seconds to respond on the first request after inactivity. This is expected, so wait a moment and try again.
</Note>

- All request bodies must use `Content-Type: application/json`
- All timestamps are UTC in ISO 8601 format
- All IDs are UUIDs (version 4)
- Unknown fields in the request body are silently ignored
- Deletion is permanent and cannot be undone
