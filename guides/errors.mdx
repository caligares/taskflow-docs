## Formato das respostas de erro

Todos os erros seguem esta estrutura:

```json
{
  "error": "Not Found",
  "message": "No project found with project_id 'abc123'."
}
```

- `error` é um tipo de erro curto e consistente, útil para tratamento programático
- `message` traz uma explicação em texto simples do que deu errado

---

## Códigos de status

### 400 Bad Request

O body da requisição está faltando um campo obrigatório ou contém um valor inválido.

**Causas comuns e mensagens exatas:**

| Erro | Mensagem retornada |
|------|--------------------|
| `name` ausente no `POST /projects` | `"The 'name' field is required and must be a non-empty string."` |
| `title` ausente no `POST /tasks` | `"The 'title' field is required and must be a non-empty string."` |
| Valor de `status` inválido | `"Invalid status 'Done'. Allowed values are: pending, in_progress, done."` |

<Note>
  Os valores de status são **case-sensitive**. `"done"` funciona. `"Done"` e `"DONE"` retornam 400.
</Note>

<Note>
  Campos desconhecidos (como `"prioridade": "alta"`) são silenciosamente ignorados. A API processa os campos válidos e retorna sucesso.
</Note>

**Como resolver:** Verifique o body da requisição na [Referência da API](/api-reference/overview). Confirme que todos os campos obrigatórios estão presentes e os valores correspondem aos tipos esperados.

---

### 401 Unauthorized

O header `Authorization` está ausente ou a chave de API é inválida.

**Exemplo:**
```json
{
  "error": "Unauthorized",
  "message": "Missing or invalid API key. Provide a valid key in the Authorization header as: Bearer <api_key>"
}
```

**Como resolver:** Adicione o header `Authorization: Bearer tf-live-4a8f2c1e9b3d7e6a` à sua requisição. Verifique se não há espaços extras e se o prefixo `Bearer ` está incluído. Veja [Autenticação](/authentication) para mais detalhes.

---

### 404 Not Found

O recurso referenciado na URL ou no body da requisição não existe.

**Projeto não encontrado:**
```json
{
  "error": "Not Found",
  "message": "No project found with project_id 'abc123'."
}
```

**Tarefa não encontrada:**
```json
{
  "error": "Not Found",
  "message": "No task found with task_id 'abc123'."
}
```

Causas comuns:
- Usar um `project_id` ou `task_id` que nunca foi criado
- Erro de digitação no ID
- Tentar atualizar ou deletar uma tarefa que já foi deletada

**Como resolver:** Verifique o ID que está usando. Obtenha os IDs a partir da resposta do `POST /projects` ou `POST /tasks`.

## Tratando erros no código

<CodeGroup>

```python Python
import requests

response = requests.post(
    "https://test-writechoice.onrender.com/tasks",
    headers={"Authorization": "Bearer tf-live-4a8f2c1e9b3d7e6a"},
    json={"project_id": "id-invalido", "title": "Minha tarefa"}
)

if response.status_code == 404:
    error = response.json()
    print(f"Não encontrado: {error['message']}")
elif response.status_code == 400:
    error = response.json()
    print(f"Requisição inválida: {error['message']}")
elif response.ok:
    task = response.json()
    print(f"Tarefa criada: {task['task_id']}")
```

```js JavaScript
const response = await fetch("https://test-writechoice.onrender.com/tasks", {
  method: "POST",
  headers: {
    "Authorization": "Bearer tf-live-4a8f2c1e9b3d7e6a",
    "Content-Type": "application/json"
  },
  body: JSON.stringify({ project_id: "id-invalido", title: "Minha tarefa" })
});

const data = await response.json();

if (!response.ok) {
  console.error(`${response.status} ${data.error}: ${data.message}`);
} else {
  console.log("Tarefa criada:", data.task_id);
}
```

</CodeGroup>

## Referência rápida

| Código | Erro | Causa provável |
|--------|------|----------------|
| `400` | Bad Request | Campo ausente ou inválido no body da requisição |
| `401` | Unauthorized | Chave de API ausente ou inválida |
| `404` | Not Found | Projeto ou tarefa referenciado não existe |
