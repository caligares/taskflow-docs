## Visão geral

O TaskFlow exige uma cadeia de dependência. Cada recurso depende do anterior existir primeiro.

```
POST /projects -> POST /tasks -> PATCH /tasks/{id} ou DELETE /tasks/{id}
```

Não é possível pular etapas. Tentar criar uma tarefa com um `project_id` inexistente retorna `404`. Tentar atualizar ou deletar uma tarefa com um `task_id` inexistente também retorna `404`.

---

## Passo 1: Criar um projeto

Um projeto é o container principal. Você precisa criar pelo menos um antes de criar tarefas.

```bash
curl -X POST https://test-writechoice.onrender.com/projects \
  -H "Authorization: Bearer tf-live-4a8f2c1e9b3d7e6a" \
  -H "Content-Type: application/json" \
  -d '{"name": "Redesign do Site"}'
```

A resposta contém um `project_id`. **Guarde este valor**: ele é necessário no Passo 2.

```json
{
  "project_id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "name": "Redesign do Site",
  "description": null,
  "created_at": "2025-05-12T10:30:00.000Z"
}
```

<Info>
  O campo `description` é opcional ao criar um projeto. Se omitido, retorna como `null`.
</Info>

---

## Passo 2: Criar tarefas dentro do projeto

Use o `project_id` do Passo 1 para adicionar tarefas. Você pode criar quantas tarefas precisar.

```bash
curl -X POST https://test-writechoice.onrender.com/tasks \
  -H "Authorization: Bearer tf-live-4a8f2c1e9b3d7e6a" \
  -H "Content-Type: application/json" \
  -d '{
    "project_id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
    "title": "Redesenhar a homepage",
    "description": "Atualizar a seção hero e a navegação."
  }'
```

Toda nova tarefa começa com `status: "pending"` automaticamente. A resposta inclui um `task_id` que você vai usar nas etapas seguintes.

---

## Passo 3: Listar tarefas para acompanhar o progresso

A qualquer momento, busque todas as tarefas de um projeto para ver o estado atual.

```bash
curl https://test-writechoice.onrender.com/projects/a1b2c3d4-e5f6-7890-abcd-ef1234567890/tasks \
  -H "Authorization: Bearer tf-live-4a8f2c1e9b3d7e6a"
```

A resposta inclui um contador `total` junto com a lista de tarefas, útil para acompanhar o progresso.

---

## Passo 4: Atualizar tarefas conforme o trabalho avança

Use `PATCH /tasks/{task_id}` para alterar o status, título ou descrição de uma tarefa. Você pode atualizar um ou mais campos na mesma requisição.

**Marcar como em andamento:**
```bash
curl -X PATCH https://test-writechoice.onrender.com/tasks/TASK_ID \
  -H "Authorization: Bearer tf-live-4a8f2c1e9b3d7e6a" \
  -H "Content-Type: application/json" \
  -d '{"status": "in_progress"}'
```

**Marcar como concluída:**
```bash
curl -X PATCH https://test-writechoice.onrender.com/tasks/TASK_ID \
  -H "Authorization: Bearer tf-live-4a8f2c1e9b3d7e6a" \
  -H "Content-Type: application/json" \
  -d '{"status": "done"}'
```

**Atualizar título e status juntos:**
```bash
curl -X PATCH https://test-writechoice.onrender.com/tasks/TASK_ID \
  -H "Authorization: Bearer tf-live-4a8f2c1e9b3d7e6a" \
  -H "Content-Type: application/json" \
  -d '{"title": "Redesenhar homepage e nav mobile", "status": "in_progress"}'
```

<Note>
  Campos desconhecidos enviados no body são silenciosamente ignorados. A API processa apenas os campos válidos e retorna sucesso.
</Note>

---

## Passo 5: Deletar tarefas quando não forem mais necessárias

Remova tarefas concluídas ou canceladas permanentemente.

```bash
curl -X DELETE https://test-writechoice.onrender.com/tasks/TASK_ID \
  -H "Authorization: Bearer tf-live-4a8f2c1e9b3d7e6a"
```

<Warning>
  A exclusão é permanente. Não existe lixeira nem desfazer. Confirme o `task_id` antes de deletar.
</Warning>

---

## Fluxo completo resumido

```
1. POST /projects              -> obtém project_id
2. POST /tasks                 -> obtém task_id (repita para cada tarefa)
3. GET  /projects/:id/tasks    -> revisa todas as tarefas
4. PATCH /tasks/:id            -> atualiza status, título ou descrição
5. DELETE /tasks/:id           -> remove quando não for mais necessário
```

Para entender o ciclo de vida dos status especificamente, veja [Status das Tarefas](/guides/task-statuses).
