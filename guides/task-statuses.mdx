---
title: Status das Tarefas
description: Tarefas no TaskFlow têm três status possíveis. pending, in_progress e done.
---

## Os três status

Toda tarefa no TaskFlow tem um campo `status` com um de três valores:

| Status | Significado |
|--------|-------------|
| `pending` | A tarefa ainda não foi iniciada. Este é o padrão ao criar uma tarefa. |
| `in_progress` | A tarefa está sendo trabalhada ativamente. |
| `done` | A tarefa foi concluída. |

---

## Status padrão

Tarefas são sempre criadas com `status: "pending"`. Não é possível definir um status diferente no momento da criação: o campo não é aceito no body do `POST /tasks`.

```json
{
  "task_id": "f9e8d7c6-b5a4-3210-fedc-ba9876543210",
  "title": "Escrever testes",
  "status": "pending",
  ...
}
```

---

## Alterando o status

Use `PATCH /tasks/{task_id}` para alterar o status de uma tarefa a qualquer momento. Não existem transições obrigatórias: você pode mover uma tarefa para qualquer status válido a partir de qualquer outro.

```bash
curl -X PATCH https://test-writechoice.onrender.com/tasks/TASK_ID \
  -H "Authorization: Bearer tf-live-4a8f2c1e9b3d7e6a" \
  -H "Content-Type: application/json" \
  -d '{"status": "in_progress"}'
```

### Progressão típica

Embora a API não force uma direção específica, a progressão habitual é:

```
pending -> in_progress -> done
```

Você também pode voltar atrás se necessário, por exemplo, reabrindo uma tarefa concluída definindo-a de volta para `in_progress`.

---

## Valores de status inválidos

Enviar qualquer valor fora das três opções permitidas retorna `400 Bad Request`:

```json
{
  "error": "Bad Request",
  "message": "Invalid status 'Done'. Allowed values are: pending, in_progress, done."
}
```

Erros comuns:
- `"completed"` deve ser substituído por `"done"`
- `"active"` deve ser substituído por `"in_progress"`
- `"todo"` deve ser substituído por `"pending"`
- `"Done"`, `"DONE"` e `"Pending"` não são aceitos. Os valores são **case-sensitive** e precisam estar em minúsculas

---

## Verificando o status de todas as tarefas do projeto

Para ver o status atual de todas as tarefas de um projeto, use `GET /projects/{project_id}/tasks`. A resposta inclui o contador `total` e a lista completa de tarefas com seus status atuais.

```json
{
  "project_id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "total": 3,
  "tasks": [
    { "title": "Escrever testes", "status": "done", ... },
    { "title": "Deploy para staging", "status": "in_progress", ... },
    { "title": "Atualizar changelog", "status": "pending", ... }
  ]
}
```
