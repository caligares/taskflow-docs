## Como funciona a autenticação

Toda requisição à API do TaskFlow deve incluir um header `Authorization` com sua chave de API como Bearer token.

```http
Authorization: Bearer tf-live-4a8f2c1e9b3d7e6a
```

Não existe fluxo de login, gerenciamento de sessão ou expiração de token. Sua chave de API é estática e deve ser incluída em cada requisição.

---

## Adicionando o header

<CodeGroup>

```bash cURL
curl https://test-writechoice.onrender.com/projects/SEU_PROJECT_ID/tasks \
  -H "Authorization: Bearer tf-live-4a8f2c1e9b3d7e6a"
```

```python Python
import requests

headers = {"Authorization": "Bearer tf-live-4a8f2c1e9b3d7e6a"}

response = requests.get(
    "https://test-writechoice.onrender.com/projects/SEU_PROJECT_ID/tasks",
    headers=headers
)
```

```js JavaScript
const response = await fetch(
  "https://test-writechoice.onrender.com/projects/SEU_PROJECT_ID/tasks",
  {
    headers: {
      "Authorization": "Bearer tf-live-4a8f2c1e9b3d7e6a"
    }
  }
);
```

</CodeGroup>

## O que acontece se a autenticação falhar

Se você omitir o header ou usar uma chave inválida, a API retorna `401 Unauthorized`:

```json
{
  "error": "Unauthorized",
  "message": "Missing or invalid API key. Provide a valid key in the Authorization header as: Bearer <api_key>"
}
```

Causas comuns:
- O header `Authorization` está completamente ausente
- A chave está com erro de digitação ou espaços extras
- O prefixo `Bearer ` está faltando (note o espaço depois de `Bearer`)

## Boas práticas de segurança

<Warning>
  Nunca deixe sua chave de API exposta em código client-side (JavaScript no browser, apps mobile). Qualquer pessoa que consiga ver o código-fonte pode extraí-la.
</Warning>

- Armazene sua chave em uma variável de ambiente: `TASKFLOW_API_KEY=tf-live-4a8f2c1e9b3d7e6a`
- Acesse no código: `process.env.TASKFLOW_API_KEY` (Node.js) ou `os.environ["TASKFLOW_API_KEY"]` (Python)
- Adicione seu arquivo `.env` ao `.gitignore` para evitar commitar a chave no repositório
