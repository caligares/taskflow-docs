## O que é o TaskFlow?

TaskFlow é uma API de gerenciamento de tarefas. Ela fornece os blocos básicos para organizar trabalho em **projetos** e **tarefas**, acompanhar o status conforme o trabalho avança e integrar gerenciamento de tarefas em qualquer aplicação.

A API é stateless e segue as convenções padrão REST. Todas as requisições e respostas usam JSON.

## Conceitos principais

<CardGroup cols={2}>
  <Card title="Projetos" icon="folder">
    Um projeto é um container para tarefas. Toda tarefa precisa pertencer a um projeto. Crie um projeto primeiro e use o `project_id` retornado para criar tarefas dentro dele.
  </Card>
  <Card title="Tarefas" icon="check">
    Uma tarefa é uma unidade de trabalho dentro de um projeto. Tarefas têm um título, uma descrição opcional e um status que avança de `pending` para `in_progress` e depois para `done`.
  </Card>
</CardGroup>

## Como funciona

A API tem cinco endpoints:

| Método | Endpoint | O que faz |
|--------|----------|-----------|
| `POST` | `/projects` | Cria um projeto |
| `POST` | `/tasks` | Cria uma tarefa dentro de um projeto |
| `GET` | `/projects/{project_id}/tasks` | Lista todas as tarefas de um projeto |
| `PATCH` | `/tasks/{task_id}` | Atualiza o título, descrição ou status de uma tarefa |
| `DELETE` | `/tasks/{task_id}` | Remove uma tarefa permanentemente |

## Ordem das operações

As operações dependem umas das outras. A API exige esta ordem:

```
Criar projeto -> Criar tarefas -> Atualizar / Listar / Deletar tarefas
```

Não é possível criar uma tarefa sem um `project_id` válido. Não é possível atualizar ou deletar uma tarefa sem um `task_id` válido. O guia de [Fluxo Principal](/guides/core-workflow) explica isso em detalhes.
