A API **TaskFlow** é um sistema para o gerenciamento de tarefas. Com ela, você pode criar projetos, adicionar tarefas dentro desses projetos, atualizar seus status e deletá-las.

## Informação Crítica de Performance

Como esta é uma API de testes hospedada na nuvem, ela entra em modo de repouso quando ociosa. **A API pode demorar até 60 segundos para responder na primeira requisição**. Isso é o comportamento esperado.

## Autenticação

Todas as requisições feitas à API exigem autenticação. Você deve enviar um cabeçalho (header) de autorização contendo a chave de API fornecida para os testes:

```http
Authorization: Bearer tf-live-4a8f2c1e9b3d7e6a

---
```
