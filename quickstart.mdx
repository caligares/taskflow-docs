title: Início Rápido
description: Crie um projeto, adicione uma tarefa e atualize o status em menos de 5 minutos.
---

Este guia percorre o fluxo completo do TaskFlow do zero. Ao final, você terá criado um projeto, adicionado uma tarefa, atualizado o status e listado as tarefas.

## Antes de começar

Você vai precisar da sua chave de API: `tf-live-4a8f2c1e9b3d7e6a`

Inclua em cada requisição como Bearer token:

```
Authorization: Bearer tf-live-4a8f2c1e9b3d7e6a
```

<Note>
  A API pode levar até 60 segundos para responder na primeira requisição após inatividade. Aguarde e tente novamente se receber timeout.
</Note>

---

## Passo 1. Criar um projeto

Toda tarefa precisa pertencer a um projeto, então comece criando um.

<CodeGroup>

```bash cURL
curl -X POST https://test-writechoice.onrender.com/projects \
  -H "Authorization: Bearer tf-live-4a8f2c1e9b3d7e6a" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Meu Primeiro Projeto",
    "description": "Um projeto para testar a API do TaskFlow."
  }'
```

```python Python
import requests

response = requests.post(
    "https://test-writechoice.onrender.com/projects",
    headers={"Authorization": "Bearer tf-live-4a8f2c1e9b3d7e6a"},
    json={
        "name": "Meu Primeiro Projeto",
        "description": "Um projeto para testar a API do TaskFlow."
    }
)
print(response.json())
```

```js JavaScript
const response = await fetch("https://test-writechoice.onrender.com/projects", {
  method: "POST",
  headers: {
    "Authorization": "Bearer tf-live-4a8f2c1e9b3d7e6a",
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    name: "Meu Primeiro Projeto",
    description: "Um projeto para testar a API do TaskFlow."
  })
});
const data = await response.json();
console.log(data);
```

</CodeGroup>

**Resposta:**

```json
{
  "project_id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "name": "Meu Primeiro Projeto",
  "description": "Um projeto para testar a API do TaskFlow.",
  "created_at": "2025-05-12T10:30:00.000Z"
}
```

<Warning>
  Salve o `project_id` desta resposta. Você vai precisar dele no próximo passo.
</Warning>

## Passo 2. Criar uma tarefa

Use o `project_id` do Passo 1 para criar uma tarefa dentro do projeto.

<CodeGroup>

```bash cURL
curl -X POST https://test-writechoice.onrender.com/tasks \
  -H "Authorization: Bearer tf-live-4a8f2c1e9b3d7e6a" \
  -H "Content-Type: application/json" \
  -d '{
    "project_id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
    "title": "Escrever o README",
    "description": "Documentar os passos de configuração e exemplos de uso."
  }'
```

```python Python
response = requests.post(
    "https://test-writechoice.onrender.com/tasks",
    headers={"Authorization": "Bearer tf-live-4a8f2c1e9b3d7e6a"},
    json={
        "project_id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
        "title": "Escrever o README",
        "description": "Documentar os passos de configuração e exemplos de uso."
    }
)
print(response.json())
```

```js JavaScript
const response = await fetch("https://test-writechoice.onrender.com/tasks", {
  method: "POST",
  headers: {
    "Authorization": "Bearer tf-live-4a8f2c1e9b3d7e6a",
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    project_id: "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
    title: "Escrever o README",
    description: "Documentar os passos de configuração e exemplos de uso."
  })
});
const data = await response.json();
console.log(data);
```

</CodeGroup>

**Resposta:**

```json
{
  "task_id": "f9e8d7c6-b5a4-3210-fedc-ba9876543210",
  "project_id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "title": "Escrever o README",
  "description": "Documentar os passos de configuração e exemplos de uso.",
  "status": "pending",
  "created_at": "2025-05-12T10:35:00.000Z",
  "updated_at": "2025-05-12T10:35:00.000Z"
}
```

Tarefas são criadas com status `pending` por padrão. Salve o `task_id` para os próximos passos.

## Passo 3. Atualizar o status da tarefa

Marque a tarefa como em andamento usando o `task_id`.

<CodeGroup>

```bash cURL
curl -X PATCH https://test-writechoice.onrender.com/tasks/f9e8d7c6-b5a4-3210-fedc-ba9876543210 \
  -H "Authorization: Bearer tf-live-4a8f2c1e9b3d7e6a" \
  -H "Content-Type: application/json" \
  -d '{"status": "in_progress"}'
```

```python Python
response = requests.patch(
    "https://test-writechoice.onrender.com/tasks/f9e8d7c6-b5a4-3210-fedc-ba9876543210",
    headers={"Authorization": "Bearer tf-live-4a8f2c1e9b3d7e6a"},
    json={"status": "in_progress"}
)
print(response.json())
```

```js JavaScript
const response = await fetch(
  "https://test-writechoice.onrender.com/tasks/f9e8d7c6-b5a4-3210-fedc-ba9876543210",
  {
    method: "PATCH",
    headers: {
      "Authorization": "Bearer tf-live-4a8f2c1e9b3d7e6a",
      "Content-Type": "application/json"
    },
    body: JSON.stringify({ status: "in_progress" })
  }
);
const data = await response.json();
console.log(data);
```

</CodeGroup>

Busque todas as tarefas do projeto para confirmar que está tudo certo.

<CodeGroup>

```bash cURL
curl https://test-writechoice.onrender.com/projects/a1b2c3d4-e5f6-7890-abcd-ef1234567890/tasks \
  -H "Authorization: Bearer tf-live-4a8f2c1e9b3d7e6a"
```

```python Python
response = requests.get(
    "https://test-writechoice.onrender.com/projects/a1b2c3d4-e5f6-7890-abcd-ef1234567890/tasks",

)
print(response.json())
```

```js JavaScript
const response = await fetch(
```
